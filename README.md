# 📘 Glossário de Siglas da Educação Digital no Brasil

O **Glossário de Siglas da Educação Digital no Brasil** é uma aplicação web criada para reunir e apresentar, de forma clara e organizada, siglas importantes ligadas ao campo da educação digital no contexto brasileiro. O projeto facilita a consulta rápida de termos recorrentes em políticas públicas, documentos normativos, plataformas educacionais e instrumentos de gestão.

## ✨ Funcionalidades

- Organização das siglas por categorias temáticas
- Interface visual simples, limpa e responsiva
- Estrutura em cartões para leitura rápida
- Animação suave de entrada dos blocos de conteúdo
- Destaque visual por cores para cada categoria
- Navegação intuitiva em uma única página
- Design adaptado para consulta em diferentes dispositivos

## 📚 Categorias contempladas

O glossário está dividido em quatro grupos principais:

- **Leis e Políticas Públicas**
- **Documentos e Órgãos Normativos**
- **Ferramentas e Plataformas**
- **Outros Documentos**

Essas categorias ajudam a localizar rapidamente conceitos e siglas frequentemente utilizados em debates, documentos e ações voltadas à educação digital.

## 🛠️ Tecnologias Utilizadas

- **HTML5**
- **CSS3**
- **JavaScript**
- **Tailwind CSS**
- **Google Fonts**

## 🎯 Objetivo do Projeto

O projeto foi desenvolvido para servir como material de apoio a estudantes, professores, gestores e pesquisadores que atuam com educação digital e precisam compreender melhor o significado de siglas presentes em legislações, programas, plataformas e diretrizes educacionais.

A proposta é transformar uma lista de termos em uma experiência de consulta mais amigável, visualmente organizada e fácil de acessar.

## ▶️ Como usar

1. Abra o arquivo HTML em um navegador.
2. Navegue pelas categorias apresentadas na página.
3. Consulte o significado das siglas conforme o tema desejado.
4. Utilize o glossário como apoio para estudos, formação ou consulta institucional.

## 🧩 Estrutura do Conteúdo

O glossário inclui siglas relacionadas a:

- legislação educacional;
- políticas públicas de conectividade e inovação;
- órgãos normativos e comitês;
- plataformas e ambientes do MEC;
- documentos pedagógicos e administrativos.

## 🎨 Interface

A interface foi projetada com foco em legibilidade e organização visual, apresentando:

- fundo claro para leitura confortável;
- cartões com sombra suave;
- cores distintas por categoria;
- tipografia moderna;
- disposição em grid responsivo.

## 📱 Responsividade

A página foi adaptada para funcionar bem em:

- computadores
- tablets
- celulares

## 📁 Estrutura do Projeto

O projeto está concentrado em um único arquivo HTML com:

- **HTML**: organização das categorias e siglas
- **CSS**: identidade visual, paleta de cores e animações
- **Tailwind CSS**: apoio à responsividade e composição visual

## ✅ Possíveis usos

Este projeto pode ser utilizado como:

- material de apoio para formação em educação digital;

- complemento didático em cursos e oficinas;
- referência introdutória sobre siglas do campo educacional brasileiro.
